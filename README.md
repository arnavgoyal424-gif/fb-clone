# fb-clone

A Facebook-inspired website clone created while learning and practicing Git, GitHub, HTML, CSS, and JavaScript.

## 🚀 About The Project

This project is a simple Facebook clone built for learning purposes.  
The main goal of this project is to practice web development as well as understand how Git and GitHub are used to manage and track code changes.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## 📚 What I Learned

While working on this project, I am learning:

- How to create and structure a website
- How HTML, CSS, and JavaScript work together
- How to initialize a Git repository
- How to track changes using Git
- How to commit changes
- How to push code to GitHub
- How to pull changes from GitHub
- How to work with GitHub repositories

## 📌 Project Status

🚧 This project is currently under development.

I will continue adding new features and improving the design as I learn more about web development and Git/GitHub.
